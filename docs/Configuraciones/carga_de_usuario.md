# 👤 Crear un Usuario

Guía paso a paso para crear un usuario en el sistema.

---

## 1️⃣ Ingresar a Usuarios
Ir a `Configuraciones → Seguridad → Usuarios`.

<!-- ![Captura de lista de usuarios](./img/usuarios-lista.png)   -->

---

## 2️⃣ Crear un nuevo usuario
Haz clic en **Nuevo usuario**.

- [ ] Hacer clic en “Nuevo usuario”  
- [ ] Confirmar que se abre el formulario  

<!-- ![Botón Nuevo Usuario](./img/nuevo-usuario.png)   -->

---

## 3️⃣ Completar datos básicos
Completa el **Nombre de usuario** y los datos personales (email, teléfono, etc.).

:::info Campos obligatorios
Los campos marcados con **\*** son obligatorios y deben completarse.
:::

- [ ] Completar nombre de usuario  
- [ ] Completar email y teléfono  
- [ ] Revisar campos obligatorios  

<!-- ![Formulario Datos Básicos](./img/datos-basicos.png)   -->

---

## 4️⃣ Vincular el usuario a una Persona (recomendado)
En el formulario existe un campo llamado **Persona**.  
Al hacer clic se abre un modal para seleccionar una persona existente.

Si la persona aún no está creada, usa el botón **“Nuevo”** dentro del modal para abrir el formulario de creación de persona.

:::tip Consejo
Completa la mayor cantidad de datos posibles (documento, dirección, teléfono, email).  
Esto facilita búsquedas y auditoría posterior.
:::

- [ ] Seleccionar persona existente  
- [ ] O crear nueva persona desde el modal  
- [ ] Guardar y confirmar vínculo  

<!-- ![Modal Selección de Persona](./img/modal-persona.png)   -->

---

## 5️⃣ Asignar permisos (botón Enlazar / Enlace)
Dentro del formulario de usuario, haz clic en el botón **Enlazar (o Enlace)** para acceder a la lista de permisos y roles.

:::warning Principio de menor privilegio
Asigna **el mínimo de permisos necesarios** para la tarea del usuario.
:::

- [ ] Abrir lista de permisos  
- [ ] Seleccionar los roles necesarios  

<!-- ![Lista de Permisos](./img/permisos.png)   -->

---

## 6️⃣ Configurar opciones adicionales
Revisa las pestañas del formulario.  
Una pestaña importante es **Novedades**, donde se registran las acciones realizadas sobre el usuario y quién las ejecutó (historial/auditoría).

Activa la opción **Cambiar clave la primera vez** si deseas que el usuario establezca su propia contraseña al primer ingreso.  
En ese caso debes ingresar ahora una **contraseña temporal (y repetirla)** que el sistema solicitará cambiar en el primer acceso.

- [ ] Revisar pestañas adicionales  
- [ ] Activar “Cambiar clave la primera vez” si corresponde  

<!-- ![Pestaña Novedades](./img/novedades.png)   -->

---

## 7️⃣ Guardar el usuario
Verifica todos los campos y permisos seleccionados.  
Haz clic en **Guardar** o **Crear** para finalizar.

- [ ] Revisar datos y permisos  
- [ ] Guardar usuario  

<!-- ![Botón Guardar](./img/guardar-usuario.png)   -->

---
