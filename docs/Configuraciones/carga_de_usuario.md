# 👤 Crear un Usuario — Guía Paso a Paso

:::tip
Guía paso a paso para **crear un usuario** en el sistema.
:::

![Crear Usuario](/img/configuraciones/cargaUsuario.png)

## 1️⃣ Ingresar a Usuarios

✔️ Ir a `Configuraciones → Seguridad → Usuarios`

---

## 2️⃣ Crear un nuevo usuario

✔️ Hacer clic en **Nuevo usuario**  
✔️ Confirmar que se abre el formulario

---

## 3️⃣ Completar datos básicos

✔️ Completar **Nombre de usuario**  
✔️ Completar **Email** y **Teléfono**  
✔️ Revisar campos obligatorios

:::info Campos obligatorios
Los campos marcados con **\*** son obligatorios y deben completarse.
:::

---

## 4️⃣ Vincular el usuario a una Persona (recomendado)

✔️ Hacer clic en el campo **Persona**  
✔️ Seleccionar persona existente o crear nueva desde el modal  
✔️ Completar datos clave: Documento, Dirección, Teléfono, Email  
✔️ Guardar y confirmar vínculo

:::tip Consejo
Completar la mayor cantidad de datos posibles. Esto facilita búsquedas y auditoría posterior.
:::

---

## 5️⃣ Asignar permisos (botón Enlazar / Enlace)

✔️ Hacer clic en **Enlazar / Enlace**  
✔️ Abrir lista de permisos  
✔️ Seleccionar los roles necesarios

:::warning Principio de menor privilegio
Asignar **el mínimo de permisos necesarios** para la tarea del usuario.
:::

---

## 6️⃣ Configurar opciones adicionales

✔️ Revisar pestañas del formulario (incluye historial/auditoría)  
✔️ Activar **Cambiar clave la primera vez** si corresponde  
✔️ Ingresar **contraseña temporal** y repetirla

---

## 7️⃣ Guardar el usuario

✔️ Verificar todos los campos y permisos  
✔️ Hacer clic en **Guardar** o **Crear** para finalizar
