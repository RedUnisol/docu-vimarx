# 📂 Configuración de Plan de Cuentas — Guía paso a paso

:::tip
Objetivo: configurar el **plan de cuentas contable** en el sistema, utilizando una estructura jerárquica en forma de **árbol**.  
Esto permite organizar cuentas padre e hijas para reflejar la estructura contable de la entidad.
:::

---

## 1️⃣ Acceder al módulo de Plan de Cuentas

✔️ Ir a **`Contabilidad → Procesos habituales → Plan de cuentas`**  
✔️ Se mostrará la vista general con las cuentas existentes (si las hubiera)

---

## 2️⃣ Crear una cuenta padre

✔️ Hacer clic en el botón **Nuevo** (ícono de hoja en blanco)  
✔️ Se abrirá un formulario con campos a completar:  

- **Código de cuenta**  
- **Nombre / descripción**  
- **Tipo de cuenta**  
- Otros parámetros según configuración  

✔️ Guardar para registrar la cuenta padre en el sistema

---

## 3️⃣ Crear cuentas hijas (niveles inferiores)

✔️ En el listado, hacer **clic derecho** sobre la cuenta padre creada  
✔️ Seleccionar la opción **Nuevo**  
✔️ Completar nuevamente los campos requeridos en el formulario  
✔️ Guardar para que la cuenta hija quede vinculada a la cuenta padre  

💡 Este proceso puede repetirse tantas veces como sea necesario para construir la jerarquía completa.

---

## 4️⃣ Estructura en forma de árbol

✔️ Cada cuenta padre puede tener múltiples cuentas hijas  
✔️ Las cuentas hijas pueden, a su vez, tener subniveles adicionales  
✔️ El sistema mostrará la estructura en forma de **árbol contable**, facilitando la navegación y el análisis

---

:::warning Importante
- Definir correctamente las **cuentas padre** antes de crear las hijas.  
- Mantener una nomenclatura clara y consistente para evitar confusiones en reportes y conciliaciones.  
:::
