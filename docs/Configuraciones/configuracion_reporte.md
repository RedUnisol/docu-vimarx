# 📊 Configuración de Reportes — VIMARX (Guía paso a paso)

:::tip  
Objetivo: configurar y diseñar reportes en VIMARX, utilizando moldes preexistentes o creando nuevos desde cero, para su uso en distintos módulos del sistema.  
:::

---

## 1️⃣ Acceder al módulo de Reportes

✔️ Ir a `Reportes → Reportes`  
✔️ Se mostrará la lista de moldes ya creados para los distintos tipos de informes disponibles

---

## 2️⃣ Crear un nuevo reporte (molde)

✔️ Hacer clic en **Nuevo reporte** (barra superior)  
✔️ Se abrirá un modal para completar:

  • Nombre del molde de reporte  
  • Data type: tipo de dato vinculado al reporte  

✔️ Al aceptar, elegir la opción **Blank**  
✔️ El sistema abrirá el editor con una hoja en blanco

---

## 3️⃣ Diseñar el reporte

✔️ En el editor se pueden insertar:

  • Cajas de texto  
  • Imágenes  
  • Formas  
  • Códigos de barras  
  • Gráficos, entre otros

💡 También es posible editar un reporte existente:  
  → Clic derecho sobre el reporte → **Mostrar diseñador de informes**

---

## 4️⃣ Configurar campos del reporte

✔️ Volver a la lista de reportes para revisar campos clave:

  • **Is Inplace Report**: si está activado, el reporte será visible dentro del módulo correspondiente  
    Ejemplo: el reporte de socios aparecerá en el módulo Socios si esta casilla está activa  
  • **Data type**: determina el tipo de reporte y su vinculación con el módulo

:::warning Importante  
Estos campos no se editan desde la vista general.  
Para modificarlos: clic derecho sobre el reporte → **Editar**  
Esto abrirá una nueva vista con los campos configurables  
:::

---

## 5️⃣ Generar reportes desde los módulos

✔️ Desde cualquier módulo, hacer clic en el ícono **Generar reporte** (barra superior)  
✔️ Se desplegará la lista de reportes disponibles según el `data type`  
✔️ Seleccionar el reporte deseado  
✔️ El sistema abrirá una vista previa con los datos cargados

🧾 Ejemplo:  
  • Ingresar al módulo `Socios`  
  • Seleccionar el socio en cuestión  
  • Desde la barra de herramientas → **Generar reporte**  
  • Vista previa con los datos del socio

✔️ En la vista previa se podrá:  
  • Exportar  
  • Imprimir  
  • Guardar el reporte
