# 💳 Líneas de Préstamos — Guía Paso a Paso

:::tip
Esta guía describe paso a paso el flujo operativo para la gestión de **líneas de préstamos** dentro del sistema.
:::

![Crear Linea de Prestamos](/img/configuraciones/cargaLineaPrestamo.png)

## 1️⃣ Propósito y flujo general

✔️ Definir, administrar y controlar las líneas disponibles para los socios  
✔️ Establecer condiciones generales, plazos, tasas y requisitos aplicables a los préstamos individuales

:::note
Pensar la línea como “la plantilla” sobre la que se basan todos los préstamos concretos.
:::

---

## 2️⃣ Acceso al módulo

✔️ Ingresar al módulo `Préstamos → Líneas de Préstamos`  
✔️ Visualizar la lista de líneas existentes con filtros y búsqueda  
✔️ Hacer clic en **Nuevo** para crear una nueva línea  
✔️ Confirmar que se abre el formulario de alta con todos los campos necesarios

---

## 3️⃣ Completar campos principales del formulario

✔️ Completar **Nombre** (obligatorio)  
✔️ Completar **Descripción** (opcional)  
✔️ Definir **Monto máximo / mínimo**  
✔️ Configurar **Plazos** (cantidad de cuotas)  
✔️ Establecer **Tasa de interés** (anual o mensual)  
✔️ Ingresar **Requisitos especiales** (garantías, antigüedad, etc.)

:::warning Importancia
Definir todos los parámetros antes de habilitar la línea para evitar inconsistencias.
:::

---

## 4️⃣ Relación con los préstamos individuales

✔️ Usar la línea como base al cargar un **nuevo préstamo**  
✔️ Seleccionar la línea y aplicar automáticamente los parámetros definidos

---

## 5️⃣ Control y edición de líneas

✔️ Editar una línea existente desde la lista  
✔️ Verificar que el usuario tenga permisos adecuados para modificar condiciones

### Cambios críticos

✔️ Modificar tasas o plazos afecta únicamente a los **nuevos préstamos**  
✔️ Mantener condiciones originales en los préstamos ya otorgados

---

## 6️⃣ Checklist previo a habilitar la línea

✔️ **Nombre** y **Descripción** cargados  
✔️ **Monto mínimo y máximo** definidos  
✔️ **Plazos** y **Tasas** configuradas  
✔️ **Requisitos especiales** validados  
✔️ **Permisos** revisados

:::tip Consejo
Usar este checklist antes de publicar la línea para asegurarse de que no falte ningún dato
:::

---

## 7️⃣ Siguientes pasos

✔️ Habilitar la línea para que los operadores puedan asignarla al cargar préstamos  
✔️ Revisar periódicamente las condiciones y ajustar según políticas de la entidad
