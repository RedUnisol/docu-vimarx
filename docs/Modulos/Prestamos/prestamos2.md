# 💰 Préstamos

:::tip Rol
El módulo **Préstamos** permite gestionar el ciclo completo de créditos otorgados a socios, incluyendo generación, ajustes, cobranzas, migraciones, simulaciones y tareas operativas.  
Es una herramienta clave para el área financiera y administrativa de **VIMARX**.
:::
