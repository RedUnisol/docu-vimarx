# 👪 Socios

:::tip Rol
El módulo **Socios** es el corazón operativo de **VIMARX**.  
Desde aquí se estructura, administra y vincula toda la información de los asociados, funcionando como base troncal que conecta **datos personales, comerciales, documentales y operativos**.

:::

---

## 🖥️ 1. Vista General – Listado de Socios

:::info Pantalla principal
La vista inicial muestra un **listado de todos los socios** con filtros dinámicos y acceso directo a su ficha detallada.
:::

### 🔑 1.1 Columnas principales

| Campo                         | Descripción                                    |
|-------------------------------|------------------------------------------------|
| **Nro Socio**                 | Identificador único interno                    |
| **CUIT / CUIL**               | Clave impositiva o laboral                     |
| **Nombre Completo**           | Apellido y nombre en formato estándar          |
| **Nro Documento**             | Documento de identidad                         |
| **Fecha de Nacimiento / Edad**| Datos demográficos básicos                     |
| **Categoría Actual**          | Categoría societaria o convenio vigente        |
| **Domicilio**                 | Dirección registrada en el sistema             |

### 🔎 1.2 Funcionalidades principales

- 🔍 **Búsqueda rápida:** filtrar por nombre, documento, categoría o cualquier columna.  
- 🖱️ **Acceso directo:** doble clic sobre un socio → abre su ficha detallada.  

---

## 👤 2. Vista de Detalle – Ficha del Socio

La ficha organiza la información en **secciones** y **pestañas**, permitiendo una visión integral del socio.

### 📋 2.1 Sección Personales

| Dato                       | Detalle                                         |
|----------------------------|-------------------------------------------------|
| **Denominación y Nombre**  | Identificación principal                         |
| **Fecha de Nacimiento / Edad** | Calculada automáticamente                   |
| **Estado / Estado Civil / Vive** | Situación personal                        |
| **Sexo**                   | Masculino / Femenino                            |
| **Datos de Contacto**      | Teléfonos y correo electrónico                  |
| **Foto**                   | Imagen almacenada en el sistema                 |

---

### 🏢 2.2 Sección Datos Mutual

- **Nro Socio y Caja**  
- **Beneficio / Dependencia / Convenio / Nro Agente**  
- **Tipo Doc / Nro Documento / CUIT**  
- **Domicilio y Código Postal**  

---

### 💰 2.3 Sección Bancaria y Económica

- **CBU / Nro Cuenta / Banco**  
- **Categoría Actual y Fecha de Alta**  
- **Responsabilidad IVA / Tipo Persona Jurídica**  
- **Actividad Principal / Cambio de Categoría**  
- **Monto Depósitos Anual** *(indicador económico)*  
- **Flags Normativos:** PEP / Sujeto Obligado  

---

### 🗂️ 2.4 Pestañas Funcionales

| Pestaña         | Contenido principal                                                                 |
|-----------------|-------------------------------------------------------------------------------------|
| **Societarios** | Historial de categorías, movimientos y resúmenes de cuenta asociados                |
| **Actividades** | Participación en eventos, asistencia y credenciales emitidas                        |
| **Económicos**  | Cuentas activas/inactivas, préstamos, ahorro, valores, movimientos de caja, indicadores históricos |

---

## 🔄 3. Flujos de Uso Típicos

1. 🆕 **Alta de socio:** registrar datos personales y societarios, asignar categoría.  
2. ✏️ **Actualización de información:** modificar datos de contacto, domicilio o categoría.  
3. 📊 **Consulta de estado:** revisar saldos, productos asociados y participación.  
4. ❌ **Baja de socio:** registrar la baja y cerrar operaciones activas.  

---

:::note ✅ Beneficios

- **Gestión integral:** toda la información del socio centralizada.  
- **Trazabilidad:** historial completo de categorías, productos y actividades.  
- **Integración:** conexión directa con módulos de cuentas, cuotas, préstamos y cobranzas.  
- **Control y cumplimiento:** alertas automáticas, verificación PEP y actualización constante de datos para reguladores.  

:::
