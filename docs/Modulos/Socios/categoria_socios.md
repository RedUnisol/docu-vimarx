# 🏷️ Categoría de Socios

:::tip Rol
El submódulo **Categoría de Socios** permite organizar, clasificar y administrar los perfiles de los asociados dentro del sistema **VIMARX**, facilitando la segmentación operativa, la asignación de permisos y la ejecución de tareas automatizadas.
:::

---

## 🖥️ 1. Vista General de Categorías

import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';

<Tabs>
<TabItem value="Principales" label="⚙️ Funciones Principales">

- ➕ Crear nuevas categorías  
- ✅ Activar o desactivar categorías existentes  
- 🗑️ Eliminar categorías seleccionadas  
- 📅 Filtrar por fechas y rangos personalizados  
- 🧹 Borrar todas las categorías (acción masiva)  
- 📋 Generar tareas vinculadas a categorías  
- 🧩 Editar modelo de categoría  
- 📥 Cargar archivo XML para importar configuraciones  

</TabItem>

<TabItem value="Secundarias" label="🛠️ Funciones Secundarias">

- 🔍 Buscar categorías por nombre, estado o fecha  
- 📊 Visualizar cantidad de socios por categoría  
- 🧾 Exportar listado de categorías  
- 🧭 Navegar entre categorías activas/inactivas  
- 🖼️ Capturar imagen de la vista para documentación  

</TabItem>
</Tabs>
