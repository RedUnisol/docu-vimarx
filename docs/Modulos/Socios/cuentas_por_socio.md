# 💳 Cuenta Socio

:::tip ROL

El submódulo **Cuenta por Socio** permite visualizar, crear y administrar las cuentas asociadas a cada socio dentro del sistema de gestión de la mutual.  
Su función principal es centralizar toda la información de las cuentas activas e históricas, así como facilitar la gestión de altas, bajas y modificaciones de datos.

:::
---

## 🖥️ 1. Pantalla Principal – Listado de Cuentas

:::info
La primera pantalla muestra un listado tabular de todas las cuentas asociadas a socios.  
Cada fila representa una cuenta individual, permitiendo **filtrar, ordenar y seleccionar** para ver su detalle.
:::

### 🔑 1.1 Columnas principales

| Icono | Campo | Descripción |
|-------|-------|-------------|
| 👤 | Socio | Nombre completo del socio en formato *Apellido, Nombre*. |
| 🆔 | Cuenta | Número único que identifica la cuenta dentro del sistema. |
| 🔗 | Tipo Relación | Indica si el socio es Titular, Adherente, etc. |
| 📅 | Fecha Alta | Fecha de creación o alta de la cuenta (formato DD/MM/AA). |
| 📄 | Nro Documento | Documento de identidad del socio (DNI / CUIT / CUIL). |
| 🔢 | Orden | Número de orden de la cuenta para el socio. |
| 🏢 | Sucursal | Sucursal o centro operativo donde está radicada la cuenta. |

### 🔎 1.2 Funcionalidad

- 🔍 Posibilidad de buscar por nombre de socio, número de cuenta o documento.  
- 🖱️ Doble clic o selección → abre el detalle de la cuenta.  

---

## 🖱️ 2. Pantalla de Detalle – Edición de Cuenta

:::info
La segunda pantalla corresponde al **detalle y edición** de la cuenta seleccionada.
:::

### 📋 2.1 Campos principales

| Icono | Campo | Descripción |
|-------|-------|-------------|
| 🆔 | Cuenta | Número único *(no editable si la cuenta ya existe)*. |
| 🔤 | Abreviatura (Abrv) | Código corto para identificar la cuenta. |
| 📝 | Descripción | Texto libre para asociar una descripción (ej. “MUDON CANCELACIONES 1000392”). |
| 👤 | Socio | Selección del socio titular o adherente *(enlace a la ficha del socio)*. |
| 🔗 | Tipo Relación | Desplegable para indicar si es Titular, Adherente, Cotitular, etc. |
| 📄 | Nro Documento | Documento de identidad del socio. |
| 📅 | Fecha Alta | Fecha en que se creó la cuenta. |
| 📅 | Fecha Terminación | Fecha de baja *(si corresponde)*. |
| 🛡️ | Tipo Garantía | Campo para indicar si la cuenta está respaldada por una garantía. |
| 📌 | Aplicada A | Campo de referencia para procesos internos. |
| 🏷️ | Tipo | Clasificación de la cuenta según la operatoria. |
| 📝 | Descripción (observaciones) | Texto libre para uso interno. |

---

## 🔄 3. Flujos de Uso Típicos

1. 📂 **Consulta de cuentas existentes:** Buscar por nombre o documento y revisar el estado.
2. ➕ **Alta de cuenta:** Crear nueva cuenta, asignando socio, tipo de relación y fecha de alta.
3. ✏️ **Modificación:** Editar datos de relación o descripción en cuentas activas.
4. ❌ **Baja:** Completar la fecha de terminación para desactivar la cuenta.

---

:::note ✅ Beneficios

- **Centralización:** toda la información de cuentas en un solo lugar.  
- **Trazabilidad:** historial de fechas y estados por socio.  
- **Facilidad de gestión:** alta y baja de cuentas sin intervención manual de sistemas.  
- **Integración:** conexión con otros módulos (créditos, cobranzas, etc.) para uso operativo.  

:::
