# 📄 Solicitudes

:::tip Rol
El módulo **Solicitudes** permite gestionar el ciclo completo de solicitudes realizadas por los socios, incluyendo simulaciones, generación de préstamos, validaciones, tareas y reportes.  
Es una herramienta clave para el área operativa y crediticia de **VIMARX**.
:::

---
