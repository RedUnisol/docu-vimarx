# 📊 Análisis del Mayor Contable

:::info[Descripción general]
El **Mayor contable** muestra el detalle de todos los movimientos que afectan una cuenta específica.  
Permite analizar la trazabilidad de operaciones provenientes de préstamos, pagos u otros procesos.
:::

## 🧭 Pasos para consultar el Mayor

---

### 1. 📂 Ingresar al módulo
Desde el menú principal:  
**`Contabilidad → Procesos habituales → Cuenta contable`**

---

### 2. 📑 Seleccionar cuenta
En el listado de cuentas contables, elegir la cuenta que se desea analizar.

---

### 3. 📊 Visualizar el Mayor
Al ingresar a la cuenta, se abrirá una vista con el **Mayor**, que incluye:  
- Todos los movimientos registrados en esa cuenta.  
- Detalle de fechas, montos y conceptos asociados.

:::note[💡 Recomendaciones]
- Usar el Mayor para detectar inconsistencias o movimientos duplicados.  
- Revisar periódicamente las cuentas más críticas (ej. bancos, préstamos).  
:::
