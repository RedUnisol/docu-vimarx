# 🧾 Gestión de Comprobantes y Cuentas a Pagar

:::info[Descripción general]
Este procedimiento permite **cargar facturas de proveedores**, establecer sus **vencimientos**, adjuntar comprobantes relacionados y generar las correspondientes **órdenes de pago** para su ejecución.
:::

## 🧭 Pasos para gestionar comprobantes y pagos

---

### 1. 🧾 Verificar proveedor

Antes de cargar una factura:

- Confirmar que el **proveedor esté dado de alta** en el sistema  
- Si no lo está, realizar el alta correspondiente

---

### 2. 📂 Crear comprobante nuevo

Ir a:

`Gestion → Proveedores → Comprobantes`

- Crear un nuevo comprobante  
- Seleccionar el **tipo de factura**: A, B, C, etc.  
- Cargar:  
  - **Número de factura**  
  - **Fecha de vencimiento**  
  - **Monto total**

---

### 3. 🧮 Añadir conceptos y resumen

- Ingresar los **conceptos asociados**:  
  Ejemplos: honorarios, marketing, reintegros  
- Completar el **resumen de la operación**

---

### 4. 📎 Adjuntar comprobantes relacionados

- Si existe documentación respaldatoria (PDF, imagen, etc.), **adjuntarla al registro** del comprobante

---

### 5. 💳 Generar orden de pago

Cuando corresponda:

- Generar la **orden de pago** desde el comprobante  
- Al ejecutar la transferencia, **cargar el comprobante de la transferencia** en el mismo registro

---

:::note[💡 Recomendaciones]
- ✅ Verificar que los datos del proveedor y factura estén completos antes de generar la orden de pago
- ✅ Adjuntar siempre los comprobantes respaldatorios para trazabilidad  
- ✅ Registrar la transferencia una vez realizada para cerrar el circuito contable
:::
