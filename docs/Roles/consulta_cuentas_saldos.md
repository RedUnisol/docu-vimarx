# 📘 Consulta de Cuentas y Saldos

:::info[Descripción general]
Este procedimiento permite realizar **consultas puntuales de cuentas contables**, revisar sus **movimientos y saldos**, y extraer información específica para reportes o controles internos.
:::

## 🧭 Pasos para consultar cuentas contables

---

### 1. 🔍 Ingresar al módulo correspondiente

Desde el menú principal, acceder a:

`Contabilidad → Procesos habituales → Asientos`  
o  
`Contabilidad → Procesos habituales → Cuenta Contable`

---

### 2. 📂 Localizar la cuenta de interés

Utilizar los filtros disponibles para buscar cuentas específicas, por ejemplo:

- Cuenta de garantía  
- FAUM  
- Otras cuentas contables relevantes

---

### 3. 📊 Verificar movimientos y saldo

Una vez localizada la cuenta:

- Revisar los **movimientos registrados** (débitos y créditos)  
- Confirmar el **saldo actual** de la cuenta

---

### 4. 📤 Extraer información puntual

Cuando se requiere información contable para:

- **Reportes internos**  
- **Controles contables**  
- **Auditorías específicas**

Se puede copiar o exportar los datos necesarios desde la vista correspondiente.
