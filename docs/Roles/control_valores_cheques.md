# 🧾 Control de Valores y Cheques

:::info[Descripción general]
Este procedimiento permite **consultar cheques cargados en el sistema**, verificar su **fecha de vencimiento** y confirmar que estén **asociados al préstamo correspondiente**, para facilitar el control contable y operativo.
:::

## 🧭 Pasos para realizar la consulta

---

### 1. 🔍 Ingresar al módulo correspondiente

Desde el menú principal, acceder a:

`Valores → Consulta de Cheques`

---

### 2. 📅 Filtrar por vencimiento y número de cheque

En la vista principal:

- Aplicar filtro por **fecha de vencimiento**  
- Aplicar filtro por **número de cheque**

Esto permite identificar los cheques próximos a vencer o realizar búsquedas específicas.

---

### 3. 🔗 Verificar asociación con préstamo

Para cada cheque listado:

- Comprobar a qué **préstamo está vinculado**  
- Validar que el vínculo sea correcto según la operación registrada

---

### 4. 📊 Usar la información para control contable

Con los datos obtenidos:

- Controlar vencimientos próximos  
- Realizar **reconciliaciones contables** entre valores y préstamos  
- Detectar posibles inconsistencias o desvinculaciones

---

:::note[💡 Recomendaciones]
- ✅ Realizar controles periódicos para evitar vencimientos sin cobertura  
- ✅ Confirmar que todos los cheques estén correctamente asociados a préstamos activos  
- ✅ Documentar cualquier inconsistencia detectada para su seguimiento
:::
