# 🔄 Gestión de Solicitudes para Transferencias (Consulta / Filtrado)

:::info[Descripción general]
Este procedimiento permite **revisar solicitudes activas** y aplicar filtros para identificar aquellas que **no deben generar salida de dinero**, así como las que se encuentran en **estados específicos** del proceso (ej. *liquidado*, *verificación de documentación*).
:::

## 🧭 Pasos para consultar y filtrar solicitudes

---

### 1. 📂 Ingresar al módulo correspondiente

Desde el menú principal, acceder a:

`Solicitudes → Solicitudes`

---

### 2. 🧮 Aplicar filtros por estado y linea

En la vista de solicitudes:

- Filtrar por **estado**:  
  Ejemplos comunes:  
  - `Liquidado`  
  - `Verificación de documentación`

- Filtrar por **linea prestamo**

---

### 3. 🔍 Revisar resultados y detectar faltantes

Para cada solicitud listada:

- Verificar si cuenta con todos los **datos necesarios** para poder transferir. 
- Identificar posibles **faltantes o inconsistencias** que impidan el proceso.
