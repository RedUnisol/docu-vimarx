# 📈 Presentación de Informes Contables

:::info[Descripción general]
El módulo de **listados contables** permite generar informes personalizados según modelo, fecha, sucursal y período.  
Estos informes pueden visualizarse en pantalla, exportarse o enviarse por correo electrónico.
:::

## 🧭 Pasos para generar un informe contable

---

### 1. 📂 Ingresar al módulo
Desde el menú principal:  
**`Contabilidad → Listados`**

---

### 2. 📑 Seleccionar modelo
Elegir el **modelo de informe** requerido

---

### 3. 📅 Definir parámetros
Configurar los filtros:  
- **Fecha**  
- **Sucursal**  
- **Período contable**  
- **Balance**  

---

### 4. 👀 Vista previa
Hacer clic en el botón **“Vista previa”** (abajo a la derecha).  
El sistema mostrará el informe con los datos seleccionados.

---

### 5. 📤 Exportar o enviar
Si el informe es correcto:  
- Exportar en el formato deseado.  
- Enviar por correo electrónico directamente desde el sistema.

:::note[💡 Recomendaciones]
- Revisar los parámetros antes de generar la vista previa.  
- Guardar copias exportadas para respaldo documental.  
:::
