# 💰 Creación de un AMT (Ahorro Mutual a Término)

:::info[Descripción general]
La creación de un **AMT** permite registrar una cuenta de **Ahorro Mutual a Término** vinculada a una cuenta **AMV existente**.  
Este proceso requiere que el usuario tenga asignado el permiso **“AMTOperador”**.
:::

## 🧭 Pasos para crear un AMT

---

### 1. 👤 Verificar alta del socio
Antes de comenzar, confirmar que el **cliente esté dado de alta como socio**.  
Si no lo está, deberá **realizarse el alta** antes de crear el AMT (ver [Alta de socio](./alta_de_socio.md)).

---

### 2. 🔗 Verificar cuenta AMV vinculada
El AMT debe estar **vinculado a una cuenta AMV** del socio.  
Por lo tanto, si el socio **no tiene una cuenta AMV**, será necesario crearla primero (ver el procedimiento de [Creación de un AMV](./nuevo_amv.md).

---

### 3. 🔐 Verificar permisos
El usuario debe poseer el permiso **“AMTOperador”** para poder crear la cuenta.  
Sin este permiso, no podrá acceder a las funciones de creación o modificación.

---

### 4. 🧭 Ingresar al módulo correspondiente
Desde el menú principal, acceder a:

`Ahorro a Término → AMT`

En la barra superior, hacer clic en el ícono de **hoja en blanco** 📝 → **“Nuevo AMT”**.

---

### 5. 🧾 Completar el formulario de creación
Se abrirá una vista con un formulario que incluye varios campos, entre ellos:

- **Socio:** seleccionar el socio correspondiente  
- **Cuenta AMV:** elegir la cuenta del socio previamente creada  
- **Plazo:** definir el período del depósito  
- **Monto a depositar**  
- **Otros parámetros** según la configuración de la entidad

Una vez completados los datos, hacer clic en **“Guardar”**.

✅ Si todo es correcto, el sistema creará el AMT y se podrá visualizar desde la **vista general del módulo AMT**.

---

### 6. ⚙️ Acciones disponibles
Desde la **barra de herramientas superior**, se podrán realizar distintas operaciones sobre el AMT:

- **Renovar / Cancelar**  
- **Realizar un anticipo**  
- **Ver o enviar reportes**

---

:::note[💡 Recomendaciones]
- Asegurarse de que el socio tenga previamente una cuenta AMV.  
- Revisar que los plazos y montos estén correctamente definidos antes de guardar.  
- Verificar los permisos **“AMTOperador”** antes de iniciar el proceso.
:::
