# 🏦 Creación de un AMV (Ahorro Mutual Variable)

:::info[Descripción general]
El proceso de **creación de un AMV** permite generar una cuenta de **Ahorro Mutual Variable** para un socio previamente registrado.  
Solo los usuarios con el permiso **“AMVOperador”** podrán realizar este procedimiento.
:::

## 🧭 Pasos para crear un AMV

---

### 1. 👤 Verificar alta del socio
Antes de iniciar, confirmar que el **propietario de la cuenta** esté **dado de alta como socio**.  
En caso contrario, será necesario realizar el **alta del socio** antes de continuar. (ver [Alta de socio](./alta_de_socio.md))

---

### 2. 🔐 Verificar permisos
Asegurarse de que el usuario actual posea el permiso **“AMVOperador”**.  
Sin este permiso, no será posible crear ni modificar cuentas AMV.

---

### 3. 🧭 Ingresar al módulo correspondiente
Desde el menú principal, acceder a:

`Cuentas → AMV Pesos`  
o  
`Cuentas → AMV Otras monedas`

> 💡 La creación del AMV es indistinta respecto del módulo en el que se realice.

---

### 4. 🆕 Crear una nueva cuenta AMV
En la **barra superior de herramientas**, hacer clic en el ícono de **hoja en blanco** 📝 → **“Nuevo AMV”**.

Esto abrirá una nueva vista con un **formulario** en el que se deben completar, entre otros, datos como:

- Tipo de cuenta  
- Socio al que se le crea el AMV  
- Sucursal correspondiente  

Una vez completados los campos, hacer clic en **“Guardar”**.  
El sistema creará la cuenta AMV para el socio seleccionado.

---

### 5. ⚙️ Operaciones posteriores
Una vez creada la cuenta AMV, desde la **barra superior de herramientas** se podrán realizar acciones como:

- Generar **préstamos** asociados  
- Realizar **nuevos movimientos**

:::warning[Importante]
Para poder realizar movimientos, es necesario que previamente estén **configurados los tipos de movimientos** correspondientes en el sistema.
:::

---

:::note[💡 Recomendaciones]
- Verificar siempre el permiso **“AMVOperador”** antes de iniciar.  
- Confirmar que el socio esté correctamente cargado en el sistema.
:::
