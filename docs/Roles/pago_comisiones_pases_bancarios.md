# 💰 Pago de Comisiones

:::info Objetivo
    Gestionar el **pago de comisiones** a vendedores dentro del sistema VIMARX.
:::

## 🧭 Pasos a seguir

---

### 1. 📂 Acceso al submodulo Comprobantes

Como primer instancia nos dirigimos a:
`Gestion → Proveedores → Comprobantes`
 
 ---

### 2. 🔍 Filtrado de Comprobantes
Traemos el campo `Centro de costo` (*clic derecho en el nombre de un campo → "Selector de columnas"*) y filtramos por el nombre correspondiente a los vendedores (ej. "Comisiones colocaciones").

---

### 3. ✅ Pago de comision
Seleccionamos la factura a la que le imputaremos el pago (estará la factura cargada) y se generará una orden de pago.
