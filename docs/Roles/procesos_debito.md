# 💳 Importar Proceso de Débitos

:::info[Descripción general]
Este procedimiento permite cargar, procesar y verificar los débitos correspondientes a cada empresa, utilizando una **plantilla preconfigurada**.
:::

## 🧭 Pasos para importar y procesar débitos

---

### 1. 🔍 Ingresar al módulo correspondiente
Desde el menú principal, acceder a:

`Préstamos → Proceso Débito`

---

### 2. 📂 Seleccionar la plantilla

En la vista principal, elegir la **plantilla creada para el proceso** de la empresa o período a trabajar.

Esto abrirá una vista con todos los débitos asociados a dicha plantilla.

---

### 3. 🆕 Crear un nuevo proceso de débito

Hacer clic en el botón **“Nuevo”**.

Se abrirá un formulario con varios campos a completar:

- Formato del archivo Excel  
- Fecha de referencia de cobro  
- Generar punitorios (sí/no)  
- Otros parámetros específicos según la empresa

---

### 4. 📤 Cargar el archivo Excel

En el campo **Archivo**, subir el documento Excel con los datos de los débitos.

:::warning[Importante]  
- El archivo debe estar configurado correctamente, respetando los **nombres de las tablas** y **códigos con su denominación** según la configuración del sistema.  
- Cualquier variación en los nombres o estructura puede provocar errores durante el procesamiento.
:::

---

### 5. ⚙️ Procesar los pagos

Una vez cargado el archivo y seleccionadas las opciones correspondientes, dirigirse a la **barra superior de herramientas** y hacer clic en **“Procesar pagos”**.

El sistema analizará el archivo y completará automáticamente los siguientes campos:

- Monto total  
- Monto procesado  
- Diferencia (en caso de existir)

---

### 6. 🧪 Revisión y corrección de diferencias

Si se detecta una diferencia o error:

- Es posible **anular el proceso** desde la barra superior  
- **Modificar el archivo Excel**  
- **Repetir el procedimiento** con el nuevo archivo corregido

---

### 7. 📤 Finalización y envío

Una vez validado el proceso y verificados los montos, se puede **enviar el resultado o informe** a la persona o área correspondiente para su gestión o control.

---

:::note[💡 Recomendaciones]
- ✅ Asegurarse de que la plantilla utilizada esté actualizada y corresponda al período correcto  
- ✅ Verificar que los códigos y denominaciones del Excel coincidan exactamente con la configuración del sistema  
- ✅ Conservar una copia del archivo Excel procesado para futuras auditorías o revisiones
:::
