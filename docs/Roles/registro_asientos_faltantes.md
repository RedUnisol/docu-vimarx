# 📑 Registro de Asientos Faltantes

:::info[Descripción general]
El registro de **asientos faltantes** permite incorporar movimientos contables que no fueron cargados previamente.  
Estos asientos luego se reflejan en el módulo de conciliaciones.
:::

## 🧭 Pasos para registrar un asiento faltante

---

### 1. 📂 Ingresar al módulo
Desde el menú principal:  
**`Contabilidad → Procesos habituales → Asientos`**

---

### 2. 📝 Crear nuevo asiento
En la barra superior, hacer clic en el ícono de **hoja en blanco** → **“Nuevo”**.

---

### 3. 🧾 Completar campos requeridos
Ingresar los datos principales:  
- **Número de asiento**  
- **Número de cuenta contable**  
- **Detalle / concepto**  
- **Monto**  

---

### 4. 💾 Guardar asiento
Confirmar la carga.  
El asiento quedará registrado y disponible para futuras conciliaciones.

:::note[💡 Recomendaciones]
- Revisar que el número de cuenta contable sea correcto.  
- Documentar claramente el concepto para facilitar auditorías posteriores.  
:::
