Configuraciones

Parámetros y ajustes necesarios para personalizar el comportamiento del sistema.

📄️ Sintaxis de criterios

Convertir el lenguaje de criterios de DevExpress en algo aprendible y confiable para personas no técnicas de VIMARX.

📄️ Reglas de validación de solicitudes

Proveer una guía conceptual y operativa para diseñar, implementar y mantener Reglas de Validación de Solicitudes en VIMARX, articuladas con flujo de estados/transiciones, comandos y notificaciones. Este texto es la base de la página del manual donde se insertarán capturas y anotaciones.

📄️ Estímulos en AMV

Comprender cómo se calculan y acreditan los estímulos (intereses) en cuentas AMV dentro de VIMARX, diferenciando conceptos clave y configuraciones.

📄️ Reportes en sistema

Este procedimiento detalla —con un enfoque exhaustivo y metodológico— las directrices para localizar, comprender, editar y desplegar reportes en el sistema VIMARX.

📄️ Crear Usuarios

Guía paso a paso para crear un usuario en el sistema.

📄️ Cargar Categorías de Socios

Guía para crear y configurar una nueva Categoría de Socio en VIMARX.

📄️ Líneas de Préstamos

Esta guía describe paso a paso el flujo operativo para la gestión de líneas de préstamos dentro del sistema.

📄️ Alta de Agente

Objetivo: dar de alta un Agente dentro del módulo Solicitudes, vinculando su usuario administrador, designando un Ejecutivo responsable, asociando Vendedores y Líneas de crédito, y finalmente activar el agente.

📄️ Configuración UIF

Guía para configurar el perfil UIF de un socio en VIMARX.

📄️ Configuración Contabilidad

Objetivo: configurar el módulo Contabilidad en VIMARX, definiendo el plan de cuentas, los asientos modelo, los periodos contables y utilidades adicionales como multimoneda y centros de costos.

📄️ Configuración de Reportes

Objetivo: configurar y diseñar reportes en VIMARX, utilizando moldes preexistentes o creando nuevos desde cero, para su uso en distintos módulos del sistema.

📄️ Flujo de Solicitudes

Este procedimiento detalla los pasos necesarios para configurar el flujo operativo de solicitudes dentro del sistema VIMARX, incluyendo grupos ejecutivos, estados, reglas de validación y apariencia dinámica.
